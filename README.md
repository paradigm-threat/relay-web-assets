# relay-web-assets

Pre-built **embed + WASM** CDN trees for Relay parked sites / SSR hydrate.

- **No npm React** on the `release` tip (`profile: embed-no-react`).
- Build with `relay-client-web`, publish with `relay-gateway/scripts/publish-web-assets.sh`.
- React-containing bundles (if ever needed) ship as a **separate release**, not mixed here.

Normative: `relay-gateway/docs/RELAY_WEB_ASSETS.md`.
